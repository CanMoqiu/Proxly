# 内置字体

**简体中文** · [English](README.en.md) · [文档目录](../../docs/README.md)

- `JetBrainsMono-Regular.ttf`：JetBrains Mono 2.304，未修改，来自 [固定上游提交](https://github.com/JetBrains/JetBrainsMono/tree/cd5227bd1f61dff3bbd6c814ceaf7ffd95e947d9) 的 `fonts/ttf/JetBrainsMono-Regular.ttf`。版权归 JetBrains，采用 SIL Open Font License 1.1。见 [许可原文](JetBrainsMono-OFL.txt) 和 [中文译本](../../docs/licenses/jetbrains-mono.zh-CN.md)。ProxlyMono 是 Flutter 中的字体族别名。
- `ProxlyFlags.woff2`：来自官方 Zashboard v3.29.1 发行包的 `TwemojiMozilla-flags-B12sb_Bp.woff2`，内容未修改，仅重命名为稳定资源名。SHA-256：`c030920068cc493d59cc8c21ff29000b7a3676c40414cba7e7a5780d02f41cbf`。Twemoji 图形版权归 Twitter 及贡献者，采用 CC BY 4.0；Mozilla 的 COLR 字体转换代码采用 Apache 2.0。见 [许可原文](Twemoji-LICENSE.md)、[中文译本](../../docs/licenses/twemoji.zh-CN.md) 和 [上游项目](https://github.com/mozilla/twemoji-colr)。仅旗帜子集由 [Zashboard](https://github.com/Zephyruso/zashboard) 提供，Proxly 未额外修改字形。

旗帜字体由 Proxly 回环服务器提供，面板单独更新后仍可使用。iOS 对区域指示符字符优先使用该字体，再使用所选文本字体；这不改变节点名称或已保存的偏好。
