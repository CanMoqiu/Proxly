## 更新内容

- 新增 iOS 18 及以上 iPhone 支持，Android 与 iOS 在主分支同步开发。
- 新增 iOS 更新提醒，可从弹窗或关于页前往 GitHub 下载新版并自签安装。
- 更新内置 Zashboard，完善关于页及双端显示适配。
- 修复 iOS Web 页面卡死及面板更新后无法恢复的问题。
- 修复 YAML 配置处理与远端备份权限相关安全问题。
- 修复了已知问题。

## 重要说明

- Android 改用固定正式签名，无法覆盖旧 26.5 的 Debug 签名版本。请先安全记录连接信息及所需设置，卸载旧版后再安装；后续同签名正式版可覆盖更新。
- iOS 包需自行签名安装，覆盖更新时保持签名身份、Bundle ID 和 Keychain 配置一致。
- YAML 文件读写需要路由器支持 SFTP，OpenWrt 可安装 `openssh-sftp-server`。
- 当前仓库为公开仓库，应用可以直接读取 GitHub Releases 中的公开版本信息；iOS 用户仍需下载 IPA 后自行签名安装。
