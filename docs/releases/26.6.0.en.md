# Proxly 26.6 release notes

[简体中文](26.6.0.md) · **English** · [Documentation](../README.en.md)

## Updates

- Added support for iPhones running iOS 18 or later, with Android and iOS developed together on the main branch.
- Added iOS update reminders; open GitHub from the update dialog or About page to download and self-sign a new version.
- Updated bundled Zashboard and improved the About page and cross-platform presentation.
- Fixed frozen iOS web pages and panel recovery after updates.
- Fixed security issues in YAML configuration handling and remote backup permissions.
- Fixed known issues.

## Important notes

- Android now uses a fixed production signing key and cannot overwrite the old 26.5 Debug-signed version. Securely record the connection details and settings you need, uninstall the old version, then install this one. Later production releases using the same signature support in-place updates.
- The iOS package requires self-signing. Keep the signing identity, Bundle ID, and Keychain configuration consistent for in-place updates.
- YAML reads/writes require SFTP support on the router; OpenWrt can install `openssh-sftp-server`.
- This repository is public, and the app can read public GitHub Releases directly. iOS users still need to download and self-sign the IPA.

## Version information

- Version: 26.6
- Platforms: Android / iOS 18+
- Packages: signed Android APK / iOS IPA requiring self-signing
