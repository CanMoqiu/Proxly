# 首页 Dashboard

首页默认依次显示 Clash 状态、当前 YAML、Clash 操作、快捷设置、流量信息和运行概览。
运行概览保留原来的连接数、累计下载/上传、速率曲线和时间刻度。

点击右上角“自定义首页”进入布局编辑模式，拖动卡片左侧手柄调整顺序，使用开关显示或隐藏卡片。
更改自动保存在本机；点击“完成”退出编辑，或选择“恢复默认”还原顺序和可见性。
即使隐藏全部卡片，也可以通过右上角入口恢复。

## YAML 配置

- “当前 YAML”显示 OpenClash 正在使用的文件名和路径；订阅或无本地文件的状态沿用现有识别逻辑。
- “切换配置”打开底部选择面板。选择文件后仍需确认，随后保存运行配置引用、重启并验证是否生效。
- “编辑配置”直接进入编辑器。顶部文件名可选择其他 YAML，这只切换编辑对象，不改变运行配置。
- 编辑器右上角的文件菜单提供上传、重命名和导出。上传同名文件需确认覆盖；导出包含当前编辑内容，不会自动写回路由器。
- 切换文件前如有未保存内容，可保存、放弃或取消。重命名保留当前编辑内容，后续保存使用新路径。
- 保存后的会话在返回时提醒是否重启 OpenClash，也可以选择稍后重启。

文件操作继续使用现有 SSH/SFTP、主机指纹确认、路径限制、大小限制和重命名回滚机制。
未安装 SFTP 服务或连接失败时，编辑器会显示错误并提供重试；读取失败的文件不可保存。

## 刷新

首页复用共享的实时数据源和重启协调器。运行数据按原有一秒间隔刷新，当前配置和快捷设置按五秒间隔同步。
隐藏的卡片不发起对应的定时读取；切换标签、进入编辑器或应用进入后台时暂停首页轮询，返回后刷新。
正在进行的读取会合并，设置变更后的旧结果不会覆盖新状态。
