# 首页 Dashboard

**简体中文** · [English](dashboard.en.md) · [文档目录](README.md)

首页默认依次显示运行状态、流量信息、运行概览、当前配置、运行操作和快捷设置。
运行概览保留原来的连接数、累计下载/上传、速率曲线和时间刻度。

滚动到卡片列表底部，点击“自定义首页”进入布局编辑模式，长按卡片后直接拖动调整顺序，使用开关显示或隐藏卡片。
开始拖动时提供振动、缩小、抬升和高亮反馈；编辑状态下卡片完整展开，不限制高度，也不产生卡片内部滚动。只有拖动中的卡片缩小并跟随手指，页面仅在手指移动到顶部或底部窄边缘区域时自动滚动；长按后未移动不会触发自动滚动，离开边缘即停止。拖动时只保留小间隔和落点提示，不提前预留整张卡片的空间；松手后保存目标顺序，以柔和动画展开卡片并排列相邻内容，取消拖动不修改顺序。编辑模式只操作布局，卡片内容不触发业务操作。主题悬浮球在点击切换主题和长按拖动时也提供振动反馈。
更改自动保存在本机；点击“完成”或切换到其他页面退出编辑，选择“恢复默认”可还原顺序和可见性。
编辑时底部按钮变为“完成”，页面保持在底部；编辑提示、恢复默认与完成按钮集中放在卡片列表下方，恢复默认后也保留底部位置。即使隐藏全部卡片，底部编辑入口仍保留，可恢复卡片。
首页操作按钮和快捷选项统一使用至少 48 的高度和 12 的圆角；操作按钮间距为 8，快捷选项共用连续底板，选中项保留主题色圆角亮框。窄屏或大字号时选项可改为纵排，文字和按钮高度随内容自适应。
卡片统一使用 16 的内容边距和圆角，卡片间距为 12，标题沿同一左侧基线排列。当前配置的刷新入口与文件信息分开排布，保留完整路径的换行空间；运行概览的统计、图表和时间刻度结构不变。
六张卡片的标题只显示名称，不附加副标题；卡片内容中的必要状态、路径和设置说明仍保留。订阅名称与流量按文字基线对齐；状态值和开关靠右，快捷设置各组使用一致的文字间距。编辑说明与恢复默认按钮分行，避免窄屏大字号下互相挤压。

快捷设置标题下直接提供 Fake-IP / Redir-Host 选择，原基础模式显示标签移除。切换时保留当前增强／兼容、TUN 或混合方式，通过既有 UCI 保存、OpenClash 重启、健康检查与模式回读确认生效。未读取、模式未知、读取失败或操作忙碌时禁用选择；保存失败不启动重启，已保存但重启失败可通过重启按钮继续恢复。

## YAML 配置

- “当前配置”显示 OpenClash 正在使用的文件名和路径；订阅或无本地文件的状态沿用现有识别逻辑。
- “切换配置”打开底部选择面板。选择文件后仍需确认，随后保存运行配置引用、重启并验证是否生效。
- “编辑配置”直接进入编辑器。顶部文件名可选择其他 YAML，这只切换编辑对象，不改变运行配置。
- 编辑器右上角的文件菜单提供上传、重命名、导出和删除。上传同名文件需确认覆盖；导出包含当前编辑内容，不会自动写回路由器。
- 删除需确认，未保存内容会一并丢弃；失败时保留编辑内容，成功后可重新选择其他 YAML。当前运行配置（包括订阅生成的配置）不能删除，需先切换配置；无法确认运行配置时也不执行删除。
- 切换文件前如有未保存内容，可保存、放弃或取消。重命名保留当前编辑内容，后续保存使用新路径。
- 重命名前核对远端真实路径，不会把其他目录的同名文件误认为当前配置；当前运行的订阅文件需先切换配置再重命名，无法确认运行配置时不执行重命名。
- 返回时重新读取正在使用的配置，仅当本次保存或上传覆盖了该文件时提醒是否重启 OpenClash。编辑或上传其他 YAML 不触发重启提醒。
- 无法确认当前运行配置时，提示用户按需手动重启，不阻止退出编辑器。

文件操作继续使用现有 SSH/SFTP、主机指纹确认、路径限制、大小限制和重命名回滚机制。
YAML 读取同时限制远端请求长度和实际累计字节；文件在读取期间增大也不能绕过 5 MiB 上限。
文件操作会检查 SFTP 握手；失败后通过当前 SSH 连接检测 OpenWrt 的组件状态。
确认缺少组件时，编辑器提供“安装 SFTP 组件”和“重新检测”。安装前显示路由器地址及命令，必须由用户确认。
自动安装要求 root 权限，识别 opkg 或 apk 后更新软件包索引并安装 `openssh-sftp-server`。
安装完成后再次验证 SFTP；原先未能打开的文件会重新读取，已有未保存内容则保留，用户可重新保存。
如果安装超时或断线，不能确定路由器是否已完成安装，应先“重新检测”，不要重复启动安装。
已有组件但握手失败会提示检查 SSH 的 SFTP 配置；普通网络或认证错误不会被当作缺少组件。
检测只随文件操作发生，不增加后台轮询。读取失败的文件不可保存。

## 刷新

首页复用共享的实时数据源和重启协调器。运行数据按原有一秒间隔刷新，当前配置和快捷设置按五秒间隔同步。
隐藏的卡片不发起对应的定时读取；切换标签、进入编辑器或应用进入后台时暂停首页轮询，返回后刷新。
正在进行的读取会合并，设置变更后的旧结果不会覆盖新状态。

首页只在右上角显示一个加载动画，汇总首次读取和正在执行的操作；卡片内保留状态文字和按钮禁用状态，运行概览布局不变。已有数据的定时刷新不显示加载动画。
离线冷启动时，当前配置和快捷设置的自动读取失败显示在卡片内，不连续弹出错误通知。恢复在线后立即重新读取 YAML 和快捷设置；断线前的旧读取结果不会覆盖恢复后的状态，也不会并发创建重复读取。
代理页、Web 连接页和独立控制台区分网络不可达、认证失败和面板初始化失败。离线时保留提示及重试按钮，仅当前可见且处于前台的离线页面每十秒检测一次控制器，恢复后重新加载面板；认证或脚本错误不会触发自动重试。iOS 局域网权限作为检查建议，不把断网直接判定为权限拒绝。
首页与 Web 页共享现有 API 和桥接请求产生的连接状态，不新增常驻轮询。重启期间统一显示重启提示，忽略旧请求结果；恢复后可见面板重建服务，隐藏面板等重新显示时再恢复。并发的恢复检测共用同一请求。HTTP 与 WebSocket 桥接都禁止跟随上游重定向。

快捷设置遇到 SSH 超时或断连时会尝试恢复事务；远端操作仍在执行或恢复结果无法验证时，显示结果未确认，不把旧值当作当前状态。原生连接列表仅在控制器确认关闭成功后移除连接，失败时保留记录并提示重试。
