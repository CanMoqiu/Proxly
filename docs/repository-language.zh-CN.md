# 仓库语言约定

**简体中文** · [English](repository-language.en.md) · [文档目录](README.md)

## 中文优先

仓库首页、文档目录、贡献与安全说明、问题表单、功能建议、使用提问、PR 模板及可配置的工作流提示默认使用简体中文。欢迎用中文交流；英文入口提供等价内容。Git 提交及推送说明允许仅使用英文。

应用的语言选择与首次启动规则保持原有行为，仓库语言约定不改变应用设置。源码注释继续沿用原有注释规则，不纳入本次文档双语改造范围。

## 中英文同步

- 每篇公开文档都有完整的中文和英文版本，在页首互相链接。
- 中文默认入口使用 `README.md`、`CONTRIBUTING.md`、`SECURITY.md` 等 GitHub 可识别的名称；专题中文文档保留现有路径，英文版使用 `.en.md`。
- 更新命令、版本、行为或限制时，同步修改两种语言。译文应覆盖操作步骤、示例、限制和验收项，不能只提供摘要。
- 英文页面优先链接到英文文档。新增文档后更新 [文档目录](README.md)。
- 问题表单提供中文默认模板和独立英文模板；讨论区的问答、建议、交流、公告与分享表单采用中文在前的中英双语提示。GitHub 不支持投票分类表单，投票正文由发起者填写。工作流提示使用中文在前、英文在后的双语文本。
- 命令、文件路径、变量、输入值、包名、校验和与外部协议标识符保持原样，避免翻译导致命令失效。

## 上游与历史材料

许可证原文、上游版权和第三方声明保留原样，中文译本通过文档目录关联；译本用于阅读，不替代原许可。上游资源内的相对路径按其原项目语境理解。

历史审查与发布说明保留所属日期、版本和当时的验证范围，提供完整译文。早期计划与后来正式发布有差异时，注明其历史性质并链接最终说明。

## GitHub 页面边界

仓库能够控制文档、模板和工作流名称及提示；GitHub 自带的导航、Settings、Actions、Run workflow 等界面文字由平台提供，不能通过仓库文件设置统一语言。文档使用“中文说明（原界面名称）”帮助定位。外部网站与第三方工具的界面也不由本仓库控制。
