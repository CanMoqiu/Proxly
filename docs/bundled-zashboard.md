# Zashboard 面板

**简体中文** · [English](bundled-zashboard.en.md) · [文档目录](README.md)

Proxly 随应用提供 Zashboard，无需在路由器上部署网页文件。代理、规则和 Web 连接页使用该面板；独立控制台提供完整网页导航。面板主题、语言和控制器连接跟随应用设置。

## 布局与连接卡片

手机使用移动布局，Android 平板和 iPad 使用桌面布局。嵌入标签页隐藏网页导航与左侧概览栏，独立控制台保留。连接页在手机和平板上均使用卡片，相同的默认内容可按需自定义。

卡片字段、表格列和代理链展示自动保存，手机和平板分别保留内容配置。显示模式与排序由应用管理，导入共享设置不会覆盖设备的连接内容配置。高级选项可切换原生连接列表与 Web 连接页。

iOS 代理页支持原生历史返回手势，可从规则返回代理。面板内的左右滑动翻页关闭，使用页面按钮或应用底栏导航。

## 导入配置

代理页右上角提供两种来源：

- **从内核导入**：读取控制器的 `/storage/zashboard`，需内核支持该接口并已保存设置。
- **从本地导入 JS 文件**：接受 `.json` 或 `.js` 扩展名的 Zashboard JSON 数据，不执行 JavaScript 程序。

文件最大 `5 MiB`，最多 `2000` 个顶层键，单个值序列化后最大 `1 MiB`。导入会过滤凭据和应用托管设置；验证失败时保留现有配置，成功后刷新已打开的面板。

## 更新与存储

在高级选项检查、下载并安装面板更新。安装前校验 SHA-256 和 ZIP 结构，失败时保留当前面板。下载成功但激活失败时，再次更新只重试激活。应用内置面板版本升级后，已下载的旧面板会清除并回到新内置版本。

HTTP 缓存定期清理，不删除连接凭据、面板偏好或已安装资源。Android 已安装版本及更旧版本的更新 APK 会在冷启动时清理，较新待安装的 APK 保留以便重试。

`assets/web_panel/` 保留上游发行资源和 MIT 许可证，不直接修改压缩后的 JavaScript。主题、认证、导航、字体及设备布局通过应用侧脚本适配；旗帜字体来源见 [字体说明](../assets/fonts/README.md)。

维护时注意以下约束：

- 平板按设备屏幕短边至少 `600` 逻辑像素识别，不随键盘或分屏窗口尺寸变化。
- 隐藏底栏仍保留视口底部的零高度定位框，供虚拟列表计算底部留白。
- `config/disable-pull-to-refresh` 固定为 `false`，避免上游全局触摸拦截阻止边缘反向滚动；回弹由原生 WebView 和 CSS 控制。
- `config/swipe-in-pages`、`config/swipe-in-tabs` 固定关闭。iOS 代理页仅关闭网页顶层路由转场，避免叠加原生返回动画。
- 更新包下载上限 `50 MiB`，最多 `2000` 项，单文件 `20 MiB`、解压总量 `100 MiB`、压缩比 `100:1`；拒绝越界路径、重复路径和符号链接。

升级资源后检查离线启动、主题语言同步、导入、设备布局、边缘滚动及 iOS 历史返回。原生集成测试不能代替真机触摸验证。
