# iOS 安装指南

**简体中文** · [English](ios-selfsign.en.md) · [文档目录](README.md)

支持 iOS 18+ 的 iPhone 和 iPad。iPhone 使用竖屏，iPad 支持横竖屏。应用管理路由器上的代理服务，不在设备上运行代理内核。

## 安装与更新

1. 从 [Releases](https://github.com/CanMoqiu/Proxly/releases) 下载 IPA，核对发布正文的 SHA-256。
2. 将 IPA 导入你使用的自签工具，按工具要求签名安装，并完成 iOS 提示的信任或开发者模式设置。
3. 更新或续签时保持实际 Bundle ID、签名身份和 Keychain 访问配置一致，覆盖安装。工程 Bundle ID 为 `top.canmoqiu.proxly`；卸载或改变签名配置可能影响本地配置和凭据访问。

核对摘要可使用以下任一命令，将 `FILE.ipa` 替换为下载路径：

```powershell
Get-FileHash -Algorithm SHA256 FILE.ipa
```

```sh
shasum -a 256 FILE.ipa
```

应用更新提醒会打开发布页，下载新包后按相同步骤安装。证书有效期和续签方式由所用工具决定。自行编译见 [双端构建指南](mobile-builds.zh-CN.md)。

## 首次连接

允许 **局域网** 权限，确保设备能访问路由器的控制器端口。拒绝过授权时，在系统设置的 Proxly 页面重新允许后重试。控制器、软件选择及 SSH 设置见 [使用指南](dashboard.zh-CN.md#连接设置)。

密码和密钥保存在仅本机、解锁时可访问的 Keychain 中，不同步到 iCloud。暂时无法读取时可重试，应用不会自动清空凭据。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 安装失败或无法启动 | 检查系统版本、签名有效期，以及工具要求的信任和开发者模式设置 |
| 控制器无法连接 | 检查局域网权限、网络、地址、端口和密钥 |
| 从后台返回后面板异常 | 使用页面重试入口；先检查路由器状态，再重复远程操作 |
| Zashboard 更新后无法加载 | 再次点击更新可重试激活；已下载成功时无需重新下载 |

应用返回前台后恢复数据刷新，不持续在后台监控。反馈问题时提供设备型号、iOS 和应用版本、复现步骤；安装问题可补充自签工具，避免附带密码、密钥或证书。
