# 弹窗交互规范

**简体中文** · [English](popup-interactions.en.md) · [文档目录](README.md)

适用于原生页面和 Web 页的原生工具栏；Zashboard 内部菜单由上游管理。

## 组件选择

| 用途 | 组件 | 行为 |
| --- | --- | --- |
| 单选、文件操作、导入来源 | `AppOptionsSheet` | 标记当前项，点选返回值；遮罩、下滑或返回取消 |
| 操作或安全确认 | `AppDialog` | 主按钮写明动作，仅明确确认后执行 |
| 文件名、SSH 密码 | `AppDialog` 内表单 | 就地显示错误，失败保留输入 |
| 连接详情 | `AppPopup.sheet` | 统一安全区、边距和拖动指示条 |
| 短结果提示 | `AppFeedback` | 使用统一时长和位置 |
| 持续故障或重启 | 页面状态及恢复入口 | 关闭界面不表示撤销远端操作 |

## 结果与异步操作

使用 `AppPopup.dialog` / `AppPopup.sheet` 打开，通过 `AppPopup.close` 返回结果。同一来源的重复打开返回空值；不同来源的 SSH 安全确认仍可展示。

结果须在退场动画和遮罩结束后返回，再打开下一层确认或系统选择器。退场中重复点击不能关闭底层页面。业务调用方负责请求互斥、端点校验、超时和重试；弹窗组件不发起路由器请求。

删除操作置于列表末尾并使用危险色。删除、覆盖、安装及 SSH 信任须确认。未保存内容提供继续编辑、放弃、保存并继续；保存失败停留在当前文件。

提交期间按操作需要禁用按钮和返回，防止重复请求。SSH 密码保存时禁用提交、取消及系统返回；关闭下载弹窗会取消下载。异步完成后须检查页面仍有效，避免关闭其他路由。

## 布局与检查

底部面板统一标题、间距和安全区，长内容滚动。居中弹窗的内容与按钮分开，三个按钮纵排，两个按钮在宽度不足时换行。表单保留键盘避让和就地校验。

检查中英文、大字号、短屏、深浅主题及双端返回行为，重点覆盖重复提交、顺序确认、取消、失败保留输入，以及关闭后的异步回调。
