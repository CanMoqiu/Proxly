# 弹窗与按钮交互规范

**简体中文** · [English](popup-interactions.en.md) · [文档目录](README.md)

Proxly 原生界面与 Web 页原生工具栏共用以下规则。Zashboard 页面内部菜单由上游管理。

| 用途 | 组件 | 关闭与结果 |
| --- | --- | --- |
| 单选、文件管理、导入来源 | `AppOptionsSheet` | 点选返回值；遮罩、下滑或返回返回空值 |
| 操作确认、安全确认 | `AppDialog` | 主按钮写具体动作；只有明确同意才执行 |
| 文件名、SSH 密码输入 | `AppDialog` 中的专用表单 | 字段错误就地显示；失败保留输入 |
| 连接详情 | 专用内容配合 `AppPopup.sheet` | 统一边距、安全区、拖动指示条和关闭行为 |
| 短结果反馈 | `AppFeedback` | 沿用成功与错误提示时长 |
| 持续故障、安装和重启 | 所属页面的状态及恢复入口 | 关闭展示界面不代表撤销远端操作 |

## 展示与执行

- 统一通过 `AppPopup.dialog`、`AppPopup.sheet` 打开；按钮使用 `AppPopup.close` 返回结果。
- 同一来源上下文的重复打开请求返回空值，不共享成功结果，避免重复执行。不同来源的 SSH 信任确认仍可展示。
- 返回结果前等待退出动画及遮罩移除，然后再打开下一层确认或系统文件选择器。
- 退出动画期间再次点击不会关闭底下的页面。
- 列表标记当前选择；业务调用方选择同一配置或语言时不重复修改。
- 删除项放在操作列表末尾并显示危险色；删除、覆盖、安装和 SSH 信任保留既有确认及校验。
- 未保存编辑提供“继续编辑”“放弃修改”“保存并继续”。保存失败留在当前文件。
- 展示组件不访问路由器，不增加轮询。已有业务状态负责请求互斥、端点核对、超时、回滚和重试。

## 布局与异步操作

- 底部面板使用统一标题、选项间距、圆角和安全区，长列表滚动。
- 居中弹窗标题与正文可滚动，操作按钮保持独立；三个按钮纵向排列，两个按钮空间不足时自动换行。
- 表单保留键盘避让和输入校验；SSH 密码保存期间禁用提交及取消，并拦截系统返回。
- 更新按钮在处理时禁用，权限提示及错误留在更新弹窗中；关闭下载弹窗会设置取消标记。
- 中英文、大字体、短屏、深浅主题和 Android/iOS 共用上述规则。

## 回归重点

验证重复打开与提交、选择后顺序确认、遮罩/手势/系统返回取消、SSH 安全确认、保存失败保留编辑，以及异步结果返回前已关闭弹窗的情况。更新弹窗还需验证浏览器失败重试和长发布说明滚动。
